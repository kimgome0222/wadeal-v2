# CELLOH Review Policy (Summary)

**Full policy:** [/policies/review](/policies/review)  
**Code:** `lib/policies/content.ts` → `REVIEW_POLICY`

## 작성 자격

- 구매 확정 또는 배송완료 후
- 구매 후 **15일 이내**

## 허용 내용

- 별점 1~5
- 텍스트 후기
- 사진 리뷰 (placeholder)

## 제한

- 욕설·비방·개인정보·광고성
- 허위·조작 리뷰 → 제재
