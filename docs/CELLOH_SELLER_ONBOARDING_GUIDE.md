## 1. 입점 신청

**판매자가 할 일**
- `/seller/apply`에서 브랜드명, 사업자 정보, 담당자, 카테고리 입력
- 사업자등록증·통신판매업 신고증 업로드 (placeholder)
- 판매자 이용약관·정산·검수·개인정보 위탁 동의

**CELLOH가 확인할 일**
- 필수값·형식 검증
- 접수 알림 발송 (`application_received`)

**예상 소요:** 즉시 (제출 완료 기준)

**주의사항**
- 허위 정보 제출 시 입점 거절·계정 정지
- mock 단계: DB 저장 없음, UI 확인용

---

## 2. 서류 검토

**판매자가 할 일**
- 보완 요청 시 **48시간 이내** 재제출 (placeholder)
- `/seller/pending`에서 상태 확인

**CELLOH가 확인할 일**
- 사업자등록번호·통신판매업 신고 적합성 (future API)
- 금지 카테고리·서류 누락 확인
- 승인 → `/seller/dashboard` / 반려 → `/seller/rejected`

**예상 소요:** 3~5영업일 (placeholder)

**주의사항**
- 반려 사유는 요약만 안내 — 민감 정보 과다 노출 없음

---

## 3. 판매자 프로필 작성

**판매자가 할 일**
- `/seller/settings` — 브랜드명, 한 줄 소개, 스토리, 로고
- `docs/CELLOH_SELLER_STORY_GUIDE.md` 참고

**CELLOH가 확인할 일**
- 공개 프로필 `/sellers/[id]` 반영
- 금지 표현·과장 문구 사전 검토 (운영)

**예상 소요:** 1~2일

**주의사항**
- 스토리 없이 상품만 등록하면 전환율 저하
- “최저가·1위” 등 검증 불가 표현 금지

---

## 4. 상품 등록 요청

**판매자가 할 일**
- `/seller/products/new` — 상품명, 가격, 이미지, 배송·교환반품, 원산지
- `docs/CELLOH_PRODUCT_REGISTRATION_GUIDE.md` 참고
- 검수 요청 제출 → `/seller/product-requests`

**CELLOH가 확인할 일**
- — (검수 단계에서 진행)

**예상 소요:** 1~3일 (판매자 준비)

**주의사항**
- 승인 전까지 고객 화면 **미노출**
- 이미지·가격 오류는 반려 사유 1순위

---

## 5. 상품 검수

**판매자가 할 일**
- 반려 시 사유 확인 → 수정 → 재신청
- 상태: 작성중 / 검수요청 / 승인대기 / 반려 / 승인완료

**CELLOH가 확인할 일**
- 상품명·이미지·가격·금지품·인증 정보 검수
- 승인 → `/seller/products` 노출 / 반려 → 사유 통지

**예상 소요:** 2~5영업일 (placeholder)

**주의사항**
- 동일 상품 반복 반려 시 입점 심사 재검토 가능

---

## 6. 판매 시작

**판매자가 할 일**
- 고객 화면 노출 확인 (`/product/[id]`, `/sellers/[id]`)
- 재고·가격 최종 점검

**CELLOH가 확인할 일**
- 검색·컬렉션·추천 노출 (알고리즘)
- 기획전 신청 안내 (Growth 이상 — 초안)

**예상 소요:** 승인 직후

**주의사항**
- 판매 종료 후 가격 변경 불가 (공동구매 특성)

---

## 7. 주문·배송 처리

**판매자가 할 일**
- `/seller/orders` — 신규 주문 확인
- 영업일 **3일 이내** 송장 등록 권장
- 배송 시작 알림 → 고객 자동 통지

**CELLOH가 확인할 일**
- 배송 SLA 모니터링
- 지연 시 관리자·판매자 알림

**예상 소요:** 주문별 1~5일

**주의사항**
- 송장 미등록 → CS·페널티
- 고객 연락처 직접 노출 금지

---

## 8. 문의·리뷰 응대

**판매자가 할 일**
- `/seller/inquiries` — **48시간 이내** 1차 답변
- `/seller/reviews` — 리뷰 확인·필요 시 답글

**CELLOH가 확인할 일**
- SLA 초과 시 `inquiry_sla_warning` 알림
- 분쟁·신고 → `/admin/support` 에스컬레이션

**예상 소요:** 문의당 24~48h

**주의사항**
- 리뷰 조작·허위 답변 금지
- 욕설·개인정보 포함 답변 금지

---

## 9. 정산 확인

**판매자가 할 일**
- `/seller/finance/settlements` — 정산 예정·확정·지급 확인
- 이의 시 정산 기간 내 문의

**CELLOH가 확인할 일**
- 월 마감 → 확정 → 입금
- 수수료·공제 내역 명시

**예상 소요:** 월 1회 (placeholder)

**주의사항**
- mock 단계: 실제 입금 없음

---

## 10. 정책 위반 관리

**판매자가 할 일**
- 경고·시정 요청 즉시 대응
- `/seller/notices` 정책 변경 확인

**CELLOH가 확인할 일**
- 위반 유형별 경고 → 판매 중지 → 입점 해지
- `/seller/suspended` 처리

**예상 소요:** case-by-case

**주의사항**
- 반복 위반 시 입점 해지·정산 보류 가능
