# 금지·제한 상품 기준

> 와딜 판매자 상품 등록 및 관리자 검수 기준 (2026-05)

## 판매 금지 상품

다음 상품은 와딜 플랫폼에서 판매할 수 없습니다.

| 구분 | 예시 |
|---|---|
| 의약품 | 전문의약품, 처방전 의약품, 불법 의약품 |
| 의료기기 | 허가·신고 없는 의료기기, 치료 효능을 광고하는 미허가 기기 |
| 건강기능식품 | 식약처 미신고 제품, 허위·과장 효능 광고 |
| 주류 | 주류(법령상 통신판매 제한) |
| 담배 | 담배, 전자담배, 액상 등 |
| 성인용품 | 성인용품(별도 정책 없이는 금지) |
| 무기·위험물 | 총기, 폭발물, 독극물 등 |
| 위조·가품 | 위조상품, 불법 복제품, 명품 가품 |
| 불법 거래 | 개인정보, 계정, 이용권 불법 거래 |
| 생체·동물 | 동물, 생체 조직 등 법령 위반 거래 |
| 기타 | 법령상 통신판매가 제한된 상품, 불법 콘텐츠 |

## 과장·허위 광고 금지

다음과 같은 표현은 상품명·상세설명에 사용할 수 없습니다.

- 치료, 완치, 의약 효능 주장
- 100% 효과, 무조건 안전 등 절대적 표현
- 정품 보장(증빙 없이), 평생 A/S 등 검증 불가 표현

## 검수 시 조치

1. 금지 키워드 감지 시 관리자 알림 (`prohibited_keyword_detected`)
2. 상품 검수 체크리스트에서 금지 상품 여부 확인 필수
3. 위반 시 반려 및 판매자 안내
