## W055 (L402, auth, unknown)

Wadeal /mypage 로그인 상태 표시 문제를 고쳐줘.

현재 문제:
- 카카오 로그인은 된 상태인데 /mypage 에서 계속 "로그인이 필요해요", "카카오로 3초 만에 시작하기"가 뜬다.
- 로그인 후에는 사용자 정보가 보여야 한다.

요구사항:
1. /mypage 페이지에서 Supabase auth.getUser() 또는 auth.getSession()으로 현재 로그인 사용자를 가져와줘.
2. 로그인 상태면 아래 정보를 표시해줘.
   - 제목: 마이페이지
   - 문구: 로그인되었습니다.
   - 이메일 또는 user.id
   - 카카오 provider 정보가 있으면 표시
3. 로그인 상태가 아니면 기존처럼 로그인 필요 화면을 보여줘.
4. 새로고침해도 로그인 상태가 유지되게 해줘.
5. 로그아웃 버튼은 로그인 상태일 때만 보여줘.
6. 기존 마이페이지 메뉴는 로그인 상태일 때 보여줘.Wadeal 마이페이지 로그아웃 버튼을 동작하게 해줘.

요구사항:
1. /mypage 페이지의 "로그아웃" 메뉴 클릭 시 Supabase auth.signOut()을 실행해줘.
2. 로그아웃 성공 후 /login 페이지로 이동하게 해줘.
3. 에러가 나면 console.error로 출력해줘.
4. 버튼/메뉴 전체 영역이 클릭 가능하게 해줘.
5. 디자인은 기존 Wadeal 화이트 기반 마이페이지 스타일 유지.
