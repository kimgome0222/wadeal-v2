# CELLOH Do Not Touch Lightly

**Date:** 2026-05-29  
**Branch:** `mobile-ui`  
**Status:** Guardrails for env, infra, and generated paths

**Related:** [CELLOH_SECRET_ENV_AUDIT.md](./CELLOH_SECRET_ENV_AUDIT.md), [CELLOH_RISKY_FILES_GUIDE.md](./CELLOH_RISKY_FILES_GUIDE.md)

---

## Summary

| Path | Risk | When OK to edit |
|------|------|-----------------|
| `.env.local` | Secrets leak | Local dev only, never commit |
| `.vercel` | Deploy linkage | Intentional deploy setup |
| Supabase env vars | DB/auth break | After migration review |
| `middleware.ts` | Auth/route break | Auth/role changes with QA |
| `next-env.d.ts` | Generated | Never manual edit |
| `.next/` | Build artifact | Delete & rebuild only |
| `node_modules/` | Dependencies | `npm install` only |
| `backups/` | Local snapshots | Delete old patches freely |
| Production deploy config | Outage | Launch checklist signed |

---

## `.env.local`

| | |
|---|---|
| **Why careful** | Contains `SUPABASE_*`, `TOSS_*`, OAuth secrets |
| **When to edit** | Adding new env key locally after `CELLOH_SECRET_ENV_AUDIT.md` review |
| **Never** | Commit, paste in docs, share in screenshots |

### Backup before edit

```bash
cp .env.local backups/.env.local.backup-$(date +%Y%m%d)
```

## Supabase-related env

| Keys (examples) | Risk |
|-----------------|------|
| `NEXT_PUBLIC_SUPABASE_URL` | Wrong project → wrong data |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Client-exposed — RLS must hold |
| `SUPABASE_SERVICE_ROLE_KEY` | **Server only** — full DB bypass |

| | |
|---|---|
| **When to edit** | Staging/prod cutover with migration plan |
| **Never** | Log values, expose in client components |

### Backup

- Document key names only in `CELLOH_SECRET_ENV_AUDIT.md`  
- Rotate keys in Supabase dashboard if leaked

## Quick decision tree

```
Need to change something?
├── UI copy/layout → components/* (see RISKY_FILES_GUIDE)
├── Env/secret → STOP → SECRET_ENV_AUDIT + backup .env.local
├── DB schema → STOP → migration task + no overnight default
├── Auth/route guard → middleware.ts + auth checklist + full route QA
└── Build weird → rm -rf .next && npm run build (not node_modules first)
```
