# 판매자 상품 준수 안내

판매자가 상품을 등록·운영할 때 준수해야 할 사항입니다.

## 등록 전 확인

1. **금지 상품 여부** — `docs/PROHIBITED_PRODUCTS.md` 기준 확인
2. **카테고리별 필수 정보** — 원산지, 인증, 표시사항 등
3. **과장 광고 금지** — 치료·완치·100% 효과 등 표현 금지

## 검수 프로세스

1. 판매자 상품 등록 → `pending_review`
2. 관리자 검수 체크리스트 확인 (`product_review_checklists`)
3. 승인 시 필수 항목 완료 필요 (미완료 시 강제 승인 옵션)

## 판매자센터 UI

- `/seller/products` — 준수 안내 패널 표시
- 상품 등록 폼 연결 시 카테고리별 안내 동적 표시 예정

## 관리자 UI

- `/admin/products/[id]/edit` — 검수 체크리스트 + 카테고리 규칙 + 키워드 경고
