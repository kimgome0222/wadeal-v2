**Date:** 2026-05-29

**Status:** 검수 기준 초안

## Before you start

- 입점 **승인** 후 등록 가능
- 검수 **승인 전** 고객 화면 미노출
- mock 단계: 제출은 UI 확인용, DB 저장 없음

---

## 1. 좋은 상품명 작성법

**Do**
- 브랜드/핵심 특성 + 용량/수량 + 제품 유형  
  예: `고당도 제철 감귤 3kg`, `도톰한 물티슈 80매 x 10팩`
- 고객이 검색할 키워드 포함 (과일, 생활, 마스크팩 등)

**Don't**
- `대박`, `1위`, `최저가`, `완판임박` (검증 불가)
- 특수문자·이모지만으로 구성
- 다른 브랜드명 무단 사용

---

## 2. 대표 이미지 기준

| 항목 | 기준 |
|------|------|
| 해상도 | **1000×1000px** 이상 권장 |
| 비율 | 1:1 정사각형 |
| 배경 | 흰 배경 또는 실물 촬영 |
| 내용 | 상품 단독, 정면·핵심 특징 visible |
| 금지 | 과장 문구·워터마크·타사 로고·저작권 침해 |

---

## 3. 상세 이미지 기준

- 구성·크기·원산지·사용법·주의사항 포함
- 텍스트-only 이미지 지양 — 실물·라벨 촬영 권장
- 식품: 영양·알레르기·유통기한 표기 이미지
- 뷰티: 전성분·용량·사용기한

---

## 4. 가격·할인 설정

- **판매가:** 실제 결제 금액
- **원가(선택):** 할인율 표시용 — 허위 원가 금지
- **할인율:** `(원가−판매가)/원가` — 과장 할인율 금지
- 판매 종료 후 가격 변경 **불가** (공동구매 특성)

---

## 5. 원산지·제조사·인증 정보

| 정보 | 필수 여부 |
|------|-----------|
| 원산지 | 식품·농산 **필수** |
| 제조사 | 해당 시 필수 |
| KC·HACCP·유기농 등 | 카테고리별 **필수** |
| 유통기한·제조일 | 식품 **필수** |

미기재·허위 기재 → **반려**

---

## 6. 배송비·무료배송 기준

- 배송 방식: 택배 / 직배송 / 디지털 (placeholder)
- 배송비: 고정 / 조건부 무료 / 착불
- **무료배송 기준** 명시 (예: 3만원 이상)
- 제주·도서 산간 추가비용 별도 표기

→ `/policies/shipping`

---

## 7. 교환·반품 안내

- 교환·반품 가능 기간 (법정 + celloh 정책)
- 단순 변심 vs 판매자 귀책 구분
- 반품 배송비 부담 주체
- 개봉·사용 상품 제한

→ `/policies/refund`

---

## 8. 금지 표현

- `100%`, `완치`, `의학적 효능` (뷰티·건강)
- `국내 최저`, `업계 1위` (근거 없음)
- 타사 비방·비교 광고 (근거 없음)
- `재고 없음`, `마감임박` 허위 긴급성

---

## 9. 과장 광고 금지

- Before/After 조작 이미지
- 사용 전후 비교 (검증 불가)
- 허위 리뷰·구매 수·별점
- `공구`, `최저가` 등 celloh 정책과 충돌하는 표현

→ `docs/CELLOH_UX_WRITING_GUIDE.md`

---

## 10. 리뷰 조작 금지

- 자체·지인 리뷰 대량 등록
- 리뷰 대가 제공 (사은품·할인 조건부)
- 부정 리뷰 삭제 요구 (플랫폼 정책 위반)

위반 시 상품 내리기·입점 제재
